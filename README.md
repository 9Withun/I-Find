# I-Find

เว็บตัวอย่างสำหรับช่วยผู้ใช้ "ค้นหาและจับคู่มือถือ" ตามความต้องการ
เช่น ดูความบันเทิง อ่านข่าว และเล่นเกม พร้อมจัดอันดับ Top 3 และพาไปยังเว็บไซต์ร้านค้า/แบรนด์โดยตรง

## วิธีใช้งาน
1. เปิด `index.html`
2. กำหนดงบประมาณและระดับความสำคัญ (Entertainment / News / Gaming)
3. กดปุ่ม "จับคู่มือถือที่เหมาะสม"
4. คลิกลิงก์ "ไปยังร้านค้า" ของเครื่องที่สนใจ

> หมายเหตุ: โปรเจกต์นี้เป็นตัวกลางแนะนำสินค้า ไม่ได้ขายสินค้าเอง
