# I-Find

เว็บไซต์ตัวอย่างสำหรับช่วยผู้ใช้ค้นหาสินค้าที่เหมาะกับไลฟ์สไตล์และงบประมาณของตนเอง พร้อมลิงก์ไปยังร้านค้าออนไลน์หลายเจ้าเพื่อให้เลือกซื้อจากร้านที่พอใจมากที่สุด

## วิธีใช้งาน
1. เปิด `index.html` บนเบราว์เซอร์
2. กรอกประเภทสินค้าที่ต้องการ
3. เลือกไลฟ์สไตล์และงบประมาณ
4. กดปุ่มแสดงคำแนะนำ เพื่อดูสินค้าที่เหมาะสมพร้อมลิงก์ร้านค้า

## เทคโนโลยี
- HTML
- CSS
- Vanilla JavaScript
